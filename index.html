Projects

MLOps & Forecasting

MiBici MLOps Platform

End-to-end MLOps pipeline for bike-share demand forecasting and serving.

Python MLflow FastAPI +9
View details →

End-to-end MLOps capstone project built on 24 months of open mobility data from Guadalajara's MiBici bike-sharing system (9M+ trips, 6.6M+ hourly station records, and 472 station profiles). Built reproducible Parquet pipelines with SHA-256 data versioning and trained models across three tasks: hourly demand forecasting (Random Forest & LinearSVR), station rebalancing risk classification, and station usage segmentation (K-Means & GMM), with experiment tracking, nested hyperparameter search, and Champion/Challenger A/B testing in MLflow.

Automated data integrity and drift monitoring using DeepChecks and Evidently, alongside Pytest test suites and pip-audit security audits. Deployed real-time inference endpoints with FastAPI and Pydantic, containerized via Podman and Docker Compose, load-tested with Locust (up to 250 concurrent users and 121 req/s with 0% errors across 4 workers), and evaluated with a FinOps cloud cost analysis comparing AWS EC2 and Google Cloud Run.
